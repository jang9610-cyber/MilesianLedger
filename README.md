# 밀레시안 장부 · Milesian Ledger

마비노기의 **교역 준비, 경매장 시세 확인, 판매 금액 분배**를 한곳에서 관리하는 Windows 데스크톱 앱입니다. 교역 재료를 준비하는 체크리스트와 게임 위에 띄우는 PIP, 시장 통계, 수수료 계산기를 제공합니다.

**현재 버전: 1.1.0-beta.2 · 공개 베타**

**[Windows 실행 ZIP 다운로드](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.1.0-beta.2/MilesianLedger-v1.1.0-beta.2.zip)** · [릴리즈 페이지](https://github.com/jang9610-cyber/MilesianLedger/releases/tag/v1.1.0-beta.2) · [변경 사항](docs/releases/v1.1.0-beta.2.md)

Windows 10/11과 **.NET Framework 4.8**이 필요합니다. ZIP을 모두 압축 해제한 뒤 `MilesianLedger/MilesianLedger.exe`를 실행하세요. GitHub의 자동 생성 **Source code (zip/tar.gz)**에는 실행 파일이 없습니다. API 키를 발급하거나 앱에 입력할 필요는 없습니다.

## 주요 기능

| 메뉴 | 기능 |
| --- | --- |
| **교역 계획** | 교역품·수량 선택, 교역 보너스·운송수단·파트너 설정, 프리셋, 예상 준비 비용·판매액·적재량 비교 |
| **재료 준비** | 재료별 구매·직접 제작·확보 방식 설정, 1~5번 준비 방식 프리셋, 구매 목록과 제작·확보 목록, 준비율·남은 품목 표시 |
| **시장 통계** | 최근 24시간·7일 거래와 현재 수집된 매물 비교, 게임 경매장 형태의 분류 메뉴, 정렬·초성 검색·관심 품목·위험군 분리 |
| **수수료·분배** | 실제 판매 금액을 기준으로 수수료·쿠폰 비용 비교, 유리한 방식 강조, 1인당 분배금·잔액 계산, 분배표 이미지 복사 |
| **PIP** | 항상 위에 표시되는 작은 창에서 교역 체크리스트와 경매장 검색 사용, 메인 앱과 체크 상태 연동 |

### 교역 계획과 재료 준비

- 오아시스·카루 숲·페라 화산·칼리다 호수의 1~5티어 교역품 20종을 선택합니다. 선택한 아이콘과 품목 카드를 강조합니다.
- 완제품 구매와 직접 제작을 섞어 계획하고, 함께 쓰는 재료를 합산합니다. 제작 단위에 맞춰 필요한 수량을 계산합니다.
- 하위 재료 → 중간 제작 단계 → 최종 교환 재료 순서로 준비합니다. 방직·실, 목공·장작, 제련·금속, 실리엔, 힐웬, 허브 등 관련 재료를 모아 정렬합니다.
- **전체 시세 갱신**은 모든 지원 재료에, **구매품목만 갱신**은 현재 계획에서 구매할 재료에 공통 시세를 반영합니다.
- 계획·체크 상태를 자동 저장하며 **진행 상태 복원**과 **주간 리셋**을 제공합니다. 복원 버튼은 교역 계획·재료 준비 화면에 있습니다.

### 시장 통계와 경매장 검색

- 판매 수량·거래 건수·거래 금액·평균 단가·최저 단가·매물 수량을 확인합니다. 거래가 활발한 품목, 판매량 대비 매물이 적은 품목, 최근 평균 거래가보다 저렴한 매물을 추릴 수 있습니다.
- 평균 거래 단가가 최저 매물가의 **5배 이상**인 품목은 기본 목록에서 제외하고 **제외된 위험군 보기**에 모읍니다. 이는 가격 차이에 따른 필터이며 비정상 거래 확정 판정은 아닙니다.
- 유동 옵션이 있는 장비·토템·애뮬릿·마기그래프 등은 이름만으로 비교하기 어려워 평균 단가 비교에서 제외합니다. 기록된 최저 매물가는 표시합니다.
- PIP·시장 통계·분배 검색에서 **초성·이름 혼합 검색**과 띄어쓰기 생략을 지원합니다. 예: `ㄱㅁㅈ` → 거미줄, `가는 ㅅㅁㅊ` → 가는 실뭉치.
- 인챈트 스크롤은 인챈트 이름으로 찾고 일반·전용·개방된 전용 스크롤을 구분합니다. 이름이 확인되지 않은 혼합 시세는 표시하지 않습니다.
- 관심 품목은 로컬에 저장합니다. 이미지가 준비되지 않은 새 시장 품목에는 대체 아이콘을 표시합니다.

### 수수료와 분배금

**판매 금액은 실제로 판매한 총액을 직접 입력합니다.** 아이템 검색의 최저가·평균가는 참고 정보이며 판매 금액을 자동으로 채우지 않습니다.

기본 수수료와 프플·멤버십 할인, 쿠폰 없음 및 10·20·30·50·100% 할인 쿠폰을 비교합니다. 쿠폰 가격은 시세 자동 반영 또는 실제 구매 비용의 직접 입력을 사용합니다. 직접 입력한 비용은 갱신 후에도 유지하며, **시세** 버튼으로 자동 반영에 돌아갈 수 있습니다.

비용이 확인된 방식 중 분배할 총액이 가장 큰 방식을 강조합니다. 분배 인원·기타 비용을 반영해 1인당 금액과 잔액을 계산하고, **분배표 이미지 복사**로 결과를 클립보드에 복사합니다. **분배 초기화**는 판매 정보를 초기화하고 쿠폰 비용과 입력 방식은 유지합니다.

### PIP와 화면 설정

PIP 상단의 **교역 / 경매장 검색** 탭은 전환해도 같은 위치에 있습니다. 교역 탭의 구매·제작 체크는 메인 앱에 즉시 반영되며, 남은 품목만 표시하거나 `?` 도움말로 획득 안내를 볼 수 있습니다. 경매장 검색은 이름을 직접 입력해 수집 시점의 개당 최저가와 매물 수량을 확인합니다.

다크 모드는 메인 앱과 PIP에 함께 적용됩니다. 화면 전환·드롭다운에 애니메이션을 적용하며 출처는 한곳에 모아 제공합니다.

## 처음 사용하기와 업데이트

1. 실행 ZIP을 모두 풀고 `MilesianLedger.exe`를 실행합니다. 실행 파일과 `data`, `assets` 폴더를 함께 보관하세요.
2. 시작 화면에서 공통 경매장 정보를 불러옵니다. 완료 후에도 마차 애니메이션을 재생하며 2초 뒤 자동으로 메인 화면을 엽니다. 연결 실패 시 저장된 정보를 사용하며, 캐시가 없어도 앱을 사용할 수 있습니다. 교역을 준비한다면 교역품과 수량을 고르고 **재료 준비 방식 설정**에서 구매·제작·확보 방식을 정합니다.
3. 각 화면의 갱신 버튼으로 서버가 게시한 최신 공통 시세를 받습니다. 검색·체크·정렬은 받은 자료로 처리합니다.
4. 필요한 수량 전체를 구비하거나 제작한 뒤 체크합니다. PIP에서도 같은 목록을 사용할 수 있습니다.

업데이트할 때는 메인 앱과 PIP를 닫고 기존 폴더를 백업한 뒤, 새 ZIP을 **별도 폴더**에 풉니다. 이전 `data`에서 개인 진행·설정 파일만 옮기고 정적 데이터 전체를 덮어쓰지 마세요. 옮길 파일과 화면별 사용법은 [사용 안내](docs/USER_GUIDE.md#설치와-업데이트)에 정리되어 있습니다.

## 시세 데이터의 구조와 한계

```text
NEXON Open API → Cloudflare 정기 수집·집계 → 공통 압축 데이터 → 앱의 로컬 저장·검색·계산
```

사용자는 같은 완료 수집본을 공유합니다. 앱은 버전이 바뀐 경우 gzip 집계본을 내려받고 크기·SHA-256·내용을 검증합니다. 같은 버전은 다시 받지 않으며, 품목을 검색할 때마다 넥슨 API를 호출하지 않습니다. 갱신 버튼은 **서버의 최신 게시본을 받는 동작**으로, 전체 경매장 재수집을 즉시 시작하지 않습니다.

넥슨 API 키는 Cloudflare Secret에만 보관합니다. 배포본의 `data/auction-proxy.json`에는 공개 서버 주소만 포함합니다. 서버 오류나 다운로드 실패 시에는 이전 검증본을 유지합니다. 상세 구조는 [시장 통계 안내](docs/MARKET_STATISTICS.md), 서버 운영은 [Cloudflare 안내](server/cloudflare/README.md)를 참고하세요.

- 표시 가격은 **수집 시점의 참고 가격**입니다. 실시간 매물이나 해당 수량 전체를 살 수 있는 가격을 보장하지 않습니다. 매물 없음·미확인·오래된 자료를 구분합니다.
- 장비의 최저가는 같은 이름의 여러 옵션을 포함할 수 있습니다. 드랍된 장비의 옵션별 감정 가격은 아닙니다.
- 교역 비용은 준비 계획의 예상액입니다. 직접 확보 재료, 제작 실패 추가 소모, 보증서 비용 등은 포함하지 않습니다. 나무판·500 포션류는 완제품 구매 전용이며 새우·설탕·마늘은 NPC 구매로 표시하고 교역 비용 합계에서 제외합니다.
- 체크는 필요 수량 전체의 준비 완료를 뜻합니다. 부분 재고, 게임 인벤토리 연동, 자동 구매·판매, 일별 추이 그래프·제작 수익 분석은 제공하지 않습니다.
- 앱은 게임 메모리에 접근하거나 게임 입력을 생성하지 않습니다. PIP는 별도 Windows 창이며 게임 환경에 따라 조작 후 클릭 상태가 게임에 남는 현상이 있을 수 있습니다.

Data based on NEXON Open API.

## 개발과 검증

Windows PowerShell과 .NET Framework 4.8의 C# 컴파일러·WPF 어셈블리로 빌드합니다. 별도 .NET SDK·Windows SDK·NuGet 패키지는 필요하지 않습니다. 서버 검증에는 Node.js 24를 사용합니다.

```powershell
./build.ps1
./scripts/test.ps1
./scripts/test-market-snapshot.ps1
./scripts/test-market-insights.ps1

# 대화형 Windows 데스크톱에서 화면·체크 연동 검증
./scripts/test-pip-search-ui.ps1 -SkipBuild
./scripts/test-workspace-ui.ps1 -SkipBuild
./scripts/test-auction-settlement-ui.ps1 -SkipBuild

# 모의 응답으로 서버 검증
node --test "server/test/*.test.mjs"
node --test "server/cloudflare/*.test.mjs"
./scripts/update-proxy-items.ps1 -Check

# 개인 파일을 제외한 실행 ZIP과 SHA-256 생성
./scripts/package.ps1
```

실행 파일은 `dist/MilesianLedger/MilesianLedger.exe`, 배포 ZIP은 `dist/MilesianLedger-v1.1.0-beta.2.zip`에 생성됩니다. 기본 검증에는 실제 API 키나 경매장 호출이 필요하지 않습니다. 같은 버전의 ZIP을 다시 만들 때는 `package.ps1 -Force`를 사용합니다.

| 경로 | 내용 |
| --- | --- |
| `src/` | WPF 화면, 교역 계산, 시세 다운로드·검색, 분배 계산, 로컬 저장 |
| `data/` | 교역·획득·운송 정보와 공개 프록시 주소 |
| `assets/` | 앱 아이콘·아이템 아이콘·로딩 이미지 |
| `server/cloudflare/` | 공통 시세 수집·집계·게시 Worker |
| `server/` | 자체 호스팅을 위한 Node.js 프록시 참고 구현 |
| `tests/`, `scripts/` | 오프라인 검증, 빌드·패키징 도구 |
| `docs/` | 사용 안내, 데이터 구조, 서버 운영, 릴리즈 기록 |

개인 진행·시세 캐시·설정·키 파일과 서버 Secret은 Git과 실행 ZIP에서 제외합니다. 사용 중인 폴더를 그대로 압축하지 말고 배포 스크립트가 만든 ZIP을 사용하세요.

## 출처와 권리

교역·제작·획득 정보와 이미지의 개별 출처는 앱의 **출처** 창, `data/`의 출처 필드, `assets/item-icons/manifest.json`에서 확인할 수 있습니다.

- 아이템·획득 정보 및 이미지 참고: [라바뉴의 마비노기](https://mabi.labanyu.com/)
- 교역 판매·운송 정보 참고: [마비 교역 도우미](https://mabitrade.kro.kr/main)
- 경매장 데이터: [NEXON Open API](https://openapi.nexon.com/ko/game/mabinogi/?id=33)
- 경매장 분류 순서·계층 참고: [mabi.zip 경매장](https://mabi.zip/auction-live)

이 앱은 개인 제작 보조 도구이며 NEXON의 공식 프로그램이 아닙니다. 마비노기 관련 명칭·캐릭터·게임 이미지 등 제3자 자료의 권리는 각 권리자에게 있습니다. 생성형 이미지로 제작한 앱 아이콘과 로딩 이미지도 게임 캐릭터를 참고한 에셋입니다.

현재 별도의 오픈소스 라이선스는 지정하지 않았습니다. 저장소 공개만으로 소스와 모든 에셋에 동일한 재배포·상업 이용 권한이 부여되는 것은 아닙니다. 소스의 라이선스와 제3자 자료의 이용 조건을 각각 확인해야 합니다.

## 릴리즈 빌드 확인

`v1.1.0-beta.2`부터 실행 ZIP은 GitHub Actions의 Windows 환경에서 생성합니다. [Release Windows beta](https://github.com/jang9610-cyber/MilesianLedger/actions/workflows/release.yml) 작업에서 해당 태그의 빌드·테스트·패키징·게시 로그를 확인할 수 있습니다. 릴리즈 본문에는 소스 커밋과 실행 기록 링크를 남깁니다. SHA-256 파일은 다운로드 파일이 배포된 파일과 동일한지 확인하는 용도이며 안전성 인증을 뜻하지 않습니다.

배포 시 소스 버전과 릴리즈 노트를 준비하고 같은 버전의 `v` 태그를 푸시합니다. 태그와 앱 버전이 다르거나 테스트·파일 검증이 실패하면 게시하지 않습니다. 이미 공개된 릴리즈 파일은 덮어쓰지 않습니다. 워크플로에는 GitHub 기본 토큰만 사용하며 넥슨 API 키는 필요하지 않습니다.
