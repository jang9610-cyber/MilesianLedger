# 앱에서 사용하는 이미지

- `app-icon/barter-helper.ico`: Windows 실행 파일과 WPF에서 사용하는 픽셀아트 얼굴 아이콘.
- `app-icon/barter-helper.png`: 아이콘 원본 PNG.
- `loading-wagon-animation/frames/frame-01.png` ~ `frame-04.png`: 투명 마차 애니메이션 4프레임. 앱 빌드 시 실행 파일에 포함합니다.
- `loading-wagon-animation/wagon-sleep-bubble-loading.gif`: 같은 애니메이션의 미리보기용 GIF.
- `loading-wagon-animation/poster.png`: 첫 프레임 미리보기.
- `item-icons/`: 교역품 20종과 재료 125종의 아이콘. 개별 원문 링크는 `manifest.json`에 있습니다.

앱 아이콘과 로딩 이미지는 게임 캐릭터를 참고한 생성형 픽셀아트입니다. 게임 명칭·캐릭터·아이템 이미지 등 제3자 자료의 권리는 각 권리자에게 있습니다. 이 저장소는 모든 이미지에 일괄적인 오픈소스 라이선스를 부여하지 않습니다.
