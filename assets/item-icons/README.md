# 마비노기 교역 아이콘

물물교환에 사용하는 **교역품 20종과 재료 125종, 총 145종**의 아이콘입니다. 직접 제작용 원재료와 대체 재료, 금속괴 합성용 아라트의 결정·축복의 포션, 광석·광석 조각·철봉 등의 하위 재료를 포함합니다. 같은 아이템이 여러 교역품에 사용되면 PNG 한 개를 공유합니다.

## 파일 구성

- `png/`: 아이템 이름으로 저장한 개별 PNG 145개
- `index.html`: 이름 검색과 교역품·재료 필터가 있는 미리보기
- `manifest.json`: 아이템 이름, 기존 이름의 별칭, 계산기 데이터 ID, 파일 경로, 출처, 원본 해상도, SHA-256

압축을 푼 뒤 `index.html`을 브라우저로 열면 인터넷 없이 이미지를 볼 수 있습니다. 개별 카드의 출처 링크를 열 때만 인터넷 연결이 필요합니다.

## 앱에서 연결하기

`manifest.json`의 `items`에서 `name` 또는 `aliases`로 아이템을 찾고, 이 폴더를 기준으로 `file` 경로의 PNG를 읽으면 됩니다. `references`에는 대응하는 계산기 데이터 ID가 들어 있습니다. 하위 제작 재료는 `procurement:아이템 이름`으로 연결합니다.

다음 이름은 같은 아이템으로 연결합니다.

- `돌연변이 식물의 점액` → `돌연변이 식물의 점액질`
- `펫 놀이 세트` → `펫 놀이세트`
- `미스릴광석` → `미스릴 광석`
- `미스릴광석 조각` → `미스릴 광석 조각`

앱의 교역품, 상세 재료와 종합 목록에서 이 매핑을 사용합니다. 실행 파일과 함께 `assets/item-icons` 폴더를 보관해 주세요.

## 원본과 출처

자료 출처: [라바뉴의 마비노기](https://mabi.labanyu.com/trade), 수집일: 2026-09-10.

PNG 아이콘은 원본 크기와 투명도·배경을 유지합니다. 교역품은 40×40px이며, 재료는 아이템에 따라 크기와 가로세로 비율이 다릅니다. 미리보기는 긴 이미지의 비율을 유지하여 표시합니다.

개별 출처 페이지와 이미지 URL은 `manifest.json`에 있습니다. 게임 이미지 권리는 원권리자에게 있습니다. 이 묶음에는 경매장 API 키나 시세 데이터가 들어 있지 않으며, 미리보기에서도 경매장 API를 호출하지 않습니다.
