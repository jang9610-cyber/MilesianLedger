# 밀레시안 장부 사용 안내

**1.0.0-beta.2 공개 베타** 사용 안내입니다. Windows와 .NET Framework 4.8 런타임에서 실행하며, `MilesianLedger.exe`와 같은 위치에 있는 `data`, `assets` 폴더를 함께 보관하세요.

## 설치와 업데이트

처음 설치할 때는 [공개 베타 실행 ZIP](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.0.0-beta.2/MilesianLedger-v1.0.0-beta.2.zip)을 내려받아 원하는 폴더에 모두 압축 해제한 뒤 `MilesianLedger/MilesianLedger.exe`를 실행합니다. 압축 파일 내부에서 바로 실행하지 마세요. 별도 설치 프로그램은 없습니다.

[릴리스 페이지](https://github.com/jang9610-cyber/MilesianLedger/releases/tag/v1.0.0-beta.2)의 **Source code (zip/tar.gz)**는 개발용 소스입니다. 앱을 바로 사용하려면 파일 이름이 `MilesianLedger-v1.0.0-beta.2.zip`인 첨부 파일을 선택하세요.

기존 버전의 계획과 설정을 이어 쓰려면 다음 순서로 업데이트합니다.

1. 메인 앱과 PIP를 모두 닫고, 기존 실행 폴더 전체를 백업합니다.
2. 새 실행 ZIP을 **별도 폴더**에 모두 압축 해제합니다.
3. 기존 실행 폴더의 `data`에서 아래 개인 파일 중 존재하는 것만 새 실행 폴더의 `data`에 복사합니다.

| 개인 파일 | 저장 내용 |
| --- | --- |
| `progress.json` | 교역 계획·프리셋·준비 방식·체크 상태 |
| `progress-history.json` | 진행 상태 복원 기록 |
| `auction-settings.json` | 경매장 품목명 매핑·조회 설정 |

| `pip-settings.json` | PIP 창 설정 |

새 앱을 실행해 계획과 체크 상태가 표시되는지 확인합니다. `data` 폴더 전체를 덮어쓰지 말고 위 파일만 옮기세요. `barter-data.json`, `item-acquisition.json`, `trade-planning.json`, `auction-proxy.json`은 새 배포본의 데이터와 서버 설정을 사용합니다. API 키 파일은 필요하지 않습니다.

## 개발 빌드의 메뉴 구성

- **교역**: 교역 계획, 재료 준비
- **경매장**: 시장 통계, 수수료·분배
- **게임 중 도구**: PIP 체크리스트·경매장 검색

시장 통계와 수수료·분배는 메인 앱 안에서 전환합니다. 다른 메뉴를 다녀와도 앱을 닫기 전까지 검색 조건과 직접 입력한 정산 금액·쿠폰 비용·분배 방식이 유지됩니다. 통계는 필터와 요약을 고정하고 품목 표 안에서 스크롤합니다. 분배는 왼쪽에 입력·참고 시세, 오른쪽에 결과와 6가지 쿠폰 비교를 나란히 표시하며, 창이 작으면 각 영역 안에서 스크롤할 수 있습니다. PIP는 게임 위에 띄우는 별도 창입니다.

개발 빌드의 PIP·시장 통계·분배 검색은 초성을 지원합니다. `ㄱㅁㅈ`으로 **거미줄**, `ㅅㄹㅇ`으로 **실리엔**, `가는 ㅅㅁㅊ`으로 **가는 실뭉치**를 찾을 수 있습니다. 띄어쓰기는 생략할 수 있고 완성형·초성·영문·숫자를 섞어 입력해도 됩니다. `ㄱ`과 `ㄲ` 같은 쌍초성은 구분합니다. PIP·분배는 기존 이름 일치 결과 다음에 초성의 전체·앞부분·중간 일치 결과를 보여 주고, 시장 통계는 판매량 등 선택한 정렬을 유지합니다. 검색으로 인터넷 조회를 추가하지 않습니다.

### 시장 통계에서 품목 찾기

왼쪽 **아이템 분류**에서 게임 경매장처럼 대분류와 세부 분류를 고릅니다. **생활 재료**를 누르면 방직·제련·힐웬·매직 크래프트 등의 품목을 함께 보고, 그 아래 **천옷/방직**을 누르면 해당 분류만 봅니다. 화살표로 하위 메뉴를 접거나 펼칠 수 있고, **전체 분류**를 누르면 분류 선택을 해제합니다. 메뉴와 품목 표는 각각 스크롤됩니다.

분류 선택은 기간·이름 및 초성 검색·관심 품목·위험군 조건과 함께 적용됩니다. 참고 분류표에 없는 새 API 분류는 맨 아래 **분류 미확인**에서 원래 이름으로 찾을 수 있습니다. **판매 기회 모아보기**에서는 다음 기준으로 품목을 추립니다.

- **거래 활발**: 선택한 기간에 거래가 관측된 품목을 거래 건수가 많은 순서로 표시합니다.
- **판매량 대비 매물 부족**: 선택한 기간의 판매 수량보다 현재 수집본의 매물 수량이 적은 품목입니다. 매물이 0인 품목을 먼저, 나머지는 판매 수량 ÷ 매물 수량이 큰 순서로 표시합니다.
- **최근 거래가보다 저렴**: 현재 최저 매물 단가가 선택한 기간의 평균 거래 단가보다 낮은 품목입니다. 가격 차이의 비율이 큰 순서로 표시하며, 옵션이 다른 장비와 가격·매물 수량이 미확인인 품목은 제외합니다.

판매량과 매물은 서로 다른 수집 구간의 참고 수치입니다. 이 조건만으로 판매 속도나 수익이 확정되지는 않습니다. 가격 차이는 수수료·구매 가능 수량을 반영한 이익이 아닙니다.

**평균 단가**는 고가·저가 거래를 모두 포함한 금액 합계를 판매 수량으로 나눈 값입니다. 소수의 고가 거래가 포함되면 평소 가격보다 훨씬 높아질 수 있습니다. 평균 단가에 마우스를 올리면 합계·수량·거래 건수와 계산 기준을 볼 수 있습니다. 금액의 소수점은 반올림하지 않고 버리며, 시장 표의 가격 차이와 비율도 정수로 표시합니다. 비교·정렬과 분배 계산에는 원래 값을 사용합니다.

평균 거래가가 최저가의 **5배 이상**인 품목은 기본 목록에서 제외합니다. **제외된 위험군 보기**를 켜면 이 품목만 평균/최저가 비율 순으로 표시하며, 표의 배수와 품목 설명에서 제외 이유를 확인할 수 있습니다. 위험군 보기에서는 판매 기회 조건을 잠시 해제하고 분류·검색·관심 조건만 적용합니다. 체크를 해제하면 원래 판매 기회·정렬 설정으로 돌아갑니다. 새로운 시세를 받거나 기간을 바꾸면 위험군을 다시 판정하며, 원본 시세나 관심 품목은 삭제하지 않습니다. 이 기준은 자금 이동·거래 조작을 확정하는 판정이 아닙니다.

옵션이 있는 장비도 **최저 단가**는 표시합니다. 해당 가격이 같은 이름의 전체 매물 기준이면 도움말에 분류·옵션 차이를 안내합니다. 기록된 매물이 없으면 **매물 없음**, 가격 자료가 없으면 **미확인**으로 표시합니다. 옵션별 평균 비교와 가격 차이 판정에는 여전히 비교 가능한 품목만 사용합니다.

평균 단가는 유동 옵션이 있는 **무기·갑옷·방어 장비·액세서리·특수 장비, 토템·애뮬릿·펫 토템, 마기그래프·마기그래프 도안**만 제외합니다. 그 외 분류는 거래 내역이 있으면 표시하며, 원거리 소모품과 마기그래프용 기타 재료도 포함합니다. 이름이 구분된 인챈트의 평균은 표시하지만, 인챈트 이름이 확인되지 않은 스크롤 묶음은 평균을 내지 않습니다. 새 앱을 실행하면 기존 저장 시세에도 이 기준이 적용됩니다.

품목 앞의 **별표**로 관심 목록에 넣거나 뺄 수 있습니다. **관심 품목만**을 켜면 저장한 품목 중 현재 검색·분류 조건에 맞는 것만 표시합니다. 관심 목록은 자동 저장되며, 새 수집본에 없는 품목도 **관측 없음**으로 남습니다. 그런 품목은 판매 기회 조건을 전체 품목으로 돌려 확인할 수 있습니다. 분류·검색·별표 조작은 인터넷 조회를 추가하지 않습니다.

## 1. 교역 계획 정하기

앱을 실행하면 그랜드마스터 상인 전환을 확인하는 안내가 먼저 나옵니다. 게임에서 직접 확인한 뒤 버튼을 눌러 메인 화면으로 들어갑니다.

**교역 계획**에서 오아시스·카루 숲·페라 화산·칼리다 호수의 교역소 카드를 열고, 교역품과 목표 수량을 선택합니다. 선택한 품목은 카드와 아이콘에 강조됩니다. 이 화면의 재료 표는 필요량을 확인하는 용도입니다.

마스터리·보증서·그랜드마스터 상인·운송수단·파트너 설정을 지정하면 참고 판매액과 운송 적재량을 함께 확인할 수 있습니다. 실제 판매액과 이동 경로에 따라 결과가 달라질 수 있습니다.

교역 프리셋은 4개 교역소 전체에 적용합니다.

- **성실한 상인**: 전 품목 최대 수량
- **체리피커**: 모든 교역소의 3~5티어 최대 수량
- **극한의 한탕**: 3~5티어 한 칸씩, 칼리다 호수는 5티어
- 사용자 프리셋: 원하는 품목과 수량을 정한 뒤 이름을 입력해 저장

## 2. 재료 준비 방식 정하기

**재료 준비 → 재료 준비 방식 설정**에서 재료 카드를 누릅니다. 최종 교환 재료부터 하위 재료까지, 경매장에서 살지 직접 만들지 직접 확보할지를 정합니다.

같은 재료를 여러 교역품에서 사용하면 필요한 양을 합산합니다. 공통 재료의 준비 방식을 다른 품목에도 함께 적용할 수 있는 제안 창에서는 적용할 항목을 선택한 뒤 완료하세요.

**준비 방식 프리셋 1~5**는 재료별 구매·제작 선택을 보관합니다. 현재 번호의 설정은 자동 저장되며 다른 번호를 눌러 전환합니다. **구매·제작 선택 초기화**는 재료별 선택과 제작법을 기본 구매 방식으로 되돌리는 기능입니다. 확인 창에서 범위를 확인하세요.

## 3. 시세 가져오기

배포본에는 Cloudflare 시세 서버 주소가 설정되어 있습니다. 사용자가 API 키를 발급하거나 앱에 입력할 필요 없이 갱신 버튼으로 시세를 가져올 수 있습니다. 연결 오류나 서버·넥슨의 호출 한도가 표시되면 해당 안내를 확인하세요. 교역 계획·체크리스트와 이미 저장된 시세는 계속 사용할 수 있습니다. 별도 배포본에서 서버 주소가 설정되지 않았다면 연결 준비 안내가 표시됩니다.

- **전체 시세 갱신**: 현재 구매 방식과 관계없이 지원하는 전체 재료 시세를 조회
- **구매품목만 갱신**: 현재 선택한 교역 계획에서 경매장 구매로 지정한 재료만 조회
- **갱신 중지**: 진행 중인 조회를 중지

앱 실행, 체크, 검색, 프리셋 전환은 시세 조회를 시작하지 않습니다. 갱신당 최대 500요청까지 진행하며 대상 품목을 모두 조회하면 종료합니다. 서버는 최근 조회 결과를 잠시 재사용하며, 캐시된 가격의 조회 시각은 원래 시각을 유지합니다. 서버의 호출 예산은 모든 사용자가 공유하므로 서버 한도 안내가 나오면 나중에 다시 시도하세요.

표시 가격은 마지막으로 확인한 최저 개당 가격입니다. 매물이 바뀌거나 필요한 수량만큼 최저가 매물이 없으면 실제 구매액은 달라집니다. 조회 실패와 호출 한도 안내가 나오면 해당 표시를 확인하세요.

## 4. 체크리스트로 준비하기

**경매장 구매 체크리스트**는 경매장에서 살 품목, **제작·확보 체크리스트**는 직접 만들거나 채집·구비할 품목을 보여 줍니다. NPC 구매품도 제작·확보 목록에 포함됩니다.

목록은 **하위 재료 → 중간 제작 단계 → 최종 교환 재료** 순서로 표시됩니다. 각 단계에서는 방직·천·가죽, 장작, 금속, 실리엔, 힐웬, 허브 등 같은 재료 분류를 모아 이름순으로 정렬합니다.

필요 수량을 모두 준비한 항목을 체크하면 준비율에 반영됩니다. 재료를 모았다고 제작품이 자동으로 완성되지는 않으므로 제작을 마친 뒤 해당 제작품도 체크하세요. 상위 품목을 구비하면 그에 필요한 하위 재료 몫도 준비율에 반영되며, 최종 교환 재료를 모두 체크하면 100%가 됩니다.

**남은 품목만 보기**를 켜면 완료되거나 상위 품목 구비로 충족된 항목이 숨겨집니다. 해제하면 전체 목록이 돌아옵니다. **목록 복사**로 구매·제작·직접 확보·NPC 구매 목록을 함께 복사할 수 있습니다.

## 5. PIP 사용하기

왼쪽 **PIP 체크리스트**를 눌러 작은 항상 위 창을 엽니다. 구매와 제작·확보 탭을 전환하며 확인할 수 있고, 체크와 남은 품목 필터는 메인 앱과 연동됩니다.

개발 빌드의 PIP 상단은 **교역 / 경매장 검색** 두 탭으로 나뉩니다. **교역** 안에서 준비율과 **구매 목록 / 제작·확보 목록**을 확인합니다. 상단 탭은 화면 전환에도 같은 위치에 있으며, 검색을 마치고 교역으로 돌아오면 직전에 보던 목록과 스크롤 위치를 유지합니다.

**경매장 검색**에서 아이템 이름을 입력하면 서버가 수집한 전체 시장 품목에서 찾습니다. `가는실뭉치`처럼 띄어쓰기를 생략하거나 이름의 일부만 입력해도 됩니다. 일치하는 이름을 먼저 보여 주며, 결과가 많으면 이름을 더 입력해 좁힐 수 있습니다. 교역 탭을 다녀와도 입력한 검색어와 결과를 유지합니다.

인챈트 스크롤은 `템포`처럼 인챈트 이름으로 검색합니다. 결과는 `템포 (접미 / 랭크 6) · 전용 인챈트 스크롤` 형식이며, 접두·접미와 랭크, 일반·전용·개방된 전용 스크롤 종류를 구분해 시세를 보여 줍니다. 장비에 붙어 있는 인챈트 이름은 검색 대상에 포함하지 않습니다.

처음에는 **시세 받기**, 이후에는 **시세 갱신**으로 최신 공통 데이터를 받습니다. 검색어 입력과 탭 전환은 인터넷 조회를 하지 않으며, 받은 시세는 오프라인에서도 검색할 수 있습니다. 매물 수집 시각과 개당 최저가, 등록 건수·수량을 확인하세요. 서버의 매물 수집은 현재 2시간 간격이며 갱신 버튼이 실시간 경매장 수집을 시작하지는 않습니다. 수집 예산 부족이나 오류 시에는 이전 완료본을 유지합니다. 옵션이 있는 장비는 같은 이름의 참고 최저가로 표시되므로 드랍된 장비의 옵션별 가치와는 다를 수 있습니다.

**인챈트 이름 미확인**으로 표시되는 스크롤은 여러 인챈트가 섞인 가격을 보여 주지 않습니다. **시세 갱신**으로 공통 데이터를 받은 뒤 인챈트 이름을 입력하세요. 기존에 스크롤 종류별로 합쳐 저장한 과거 거래는 이름별로 다시 나눌 수 없으며, 이름별 거래 기록은 새로 수집한 거래부터 쌓입니다.

PIP 위로 마우스를 옮기면 PIP가 입력 포커스를 받습니다. 첫 클릭부터 체크할 수 있으며 스크롤로 목록을 이동합니다. 창 가장자리에서 크기를 조절할 수 있습니다. `?`를 누르거나 마우스를 올리면 획득·제작 안내를 확인합니다.

게임 환경에 따라 PIP 클릭 이후 클릭 상태가 마비노기에 남을 수 있습니다. 앱은 게임 입력이나 게임 내부 상태를 직접 제어하지 않습니다.

## 6. 수수료·분배 (개발 빌드)

왼쪽 **수수료·분배**에서 실제 판매한 한 건의 총액, 본인을 포함한 분배 인원, 기타 비용을 입력합니다. **프플 / 멤버십 수수료 할인**을 켜면 기본 수수료 5% 대신 4%를 적용합니다.

아이템 이름은 직접 적거나 검색 결과에서 선택합니다. 수집 시점의 최저 매물 단가와 최근 24시간·7일 평균 판매단가는 참고 정보이며, **판매 금액을 자동으로 채우거나 수정하지 않습니다.** 옵션이 다른 장비는 참고 최저가만 표시하고, 시세가 없는 이름도 그대로 사용할 수 있습니다. 검색과 화면 전환은 저장된 자료를 사용하며, **시세 갱신**을 눌렀을 때만 공통 시장 데이터를 내려받습니다.

쿠폰 없음과 10·20·30·50·100% 할인 쿠폰을 비교합니다. 각 쿠폰에 **현재 최저 매물가와 수집 시각**, 계산에 쓰는 비용의 입력 방식을 표시합니다. 기본은 **시세 자동 반영**이며, 정산 화면이나 PIP·시장 통계·교역 화면에서 공통 시세를 갱신하면 정산에도 반영합니다. 실제 구매 가격을 직접 입력하면 이후 갱신에도 그 비용을 유지하고, 참고 최저가는 별도로 갱신합니다. **보유**는 쿠폰 구매 비용을 0 G로 설정하며, **시세**를 누르면 시세 따르기(자동 반영)로 돌아갑니다.

**추천** 카드는 비용을 확인한 방식 중 분배할 총액이 가장 큰 방법을 초록색 배경과 테두리로 강조합니다. 선택한 방식과 추천은 별도이며, 판매 금액·프리미엄 할인·쿠폰 비용을 바꾸면 추천도 다시 계산합니다. 쿠폰을 사용하지 않는 것이 유리하면 **쿠폰 없음**을 추천하고, 가격 미확인은 무료로 계산하거나 추천하지 않습니다. 동률이면 할인율이 낮은 쿠폰부터 표시하며, 쿠폰 없음과 동률이면 쿠폰 없음을 우선합니다. 모든 방식이 손실이면 추천 대신 비용 최소 방식을 안내합니다.

- 예상 수수료 = 판매 총액 × 기본 수수료율 × (1 − 쿠폰 할인율)
- 분배할 총액 = 판매 총액 − 예상 수수료 − 쿠폰 비용 − 기타 비용
- 1인당 분배금 = 분배할 총액 ÷ 인원, 1 G 미만 내림
- 분배 후 남는 금액 = 분배할 총액 − 1인당 분배금 × 인원

**이 방식으로 분배**를 누른 뒤 **분배표 이미지 복사**를 누르면 아이템 이름, 판매 총액, 선택한 방식, 1인당 금액, 잔액과 전체 쿠폰 비교표를 복사합니다. 채팅창에서 Ctrl+V로 붙여넣을 수 있습니다. 계산 중인 내용은 창 안에서 유지되며 앱의 거래 기록으로 자동 저장되지는 않습니다.

한 판매 건(묶음)에 쿠폰 1장을 사용하는 계산입니다. 여러 판매 건은 각각 계산합니다. 예상 수수료는 소수점까지 유지하므로 게임의 골드 단위 처리에 따라 실제 수령액에 차이가 있을 수 있습니다. 보증 수표 발급 등 추가 비용은 기타 비용에 입력합니다. **성수 제작비 +800만 G**는 무리아스의 성수 1개 제작비 편의 입력 버튼이며, 실제 지출에 맞게 수정할 수 있습니다.

수수료와 멤버십·쿠폰 적용 기준: [넥슨 고객센터 안내](https://cs.nexon.com/helpBoard/popuphelpview/20851).

## 계산 기준

- 나무판과 500 포션류는 완제품 경매장 구매 전용입니다.
- 새우·설탕·마늘은 NPC 구매이며 경매장 조회와 비용 합계에서 제외됩니다. 새우 조련 미끼 완제품은 구매와 제작 중에서 선택합니다.
- 금속괴는 합성 증식을 추천하며, 시작용 괴와 제작 결과의 체크는 별도로 관리합니다.
- 제작은 성공 기준입니다. 실패 소모량이나 사용자가 이미 가진 부분 수량을 따로 계산하지 않습니다.
- 비용은 선택한 준비 방식과 저장된 시세에 따른 예상 금액입니다. 실제 지출 장부나 게임 인벤토리와 자동 연결되지 않습니다.

## 저장·백업·복원

계획·체크·프리셋은 실행 폴더의 `data/progress.json`에 자동 저장됩니다. **진행 상태 복원**에서는 저장된 이전 상태로 되돌리거나 현재 상태를 직접 보관할 수 있습니다. 주간 리셋 전에 진행 상황을 확인하세요.

앱을 닫은 뒤 실행 폴더를 개인 보관용으로 복사하면 설정과 진행 상태를 함께 백업할 수 있습니다. 다른 사람에게 배포할 때는 이 개인 백업을 사용하지 말고 저장소의 배포 스크립트가 만든 ZIP을 사용하세요. 이 버전은 앱에서 API 키를 저장하지 않습니다. 예전 버전의 키 파일은 더 이상 사용하지 않으며 배포 ZIP에도 포함되지 않습니다.

갱신 버튼 아래의 조회 실패는 요청했으나 가격을 확인하지 못한 품목 수입니다. 미갱신은 중단 또는 요청 한도 때문에 조회를 마치지 못한 품목 수입니다. 결과 안내에 마우스를 올리면 실패 품목과 사유를 볼 수 있습니다. 특정 품목의 검색 조건 오류는 다음 품목으로 넘어가며, 인증·호출 한도·서비스 장애가 확인되면 갱신을 중단합니다. 기존 시세가 있으면 유지합니다.
