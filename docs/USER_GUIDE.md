# 밀레시안 장부 사용 안내

**1.0.0-beta.2 공개 베타** 사용 안내입니다. Windows와 .NET Framework 4.8 런타임에서 실행하며, `MilesianLedger.exe`와 같은 위치에 있는 `data`, `assets` 폴더를 함께 보관하세요.

## 설치와 업데이트

처음 설치할 때는 [공개 베타 실행 ZIP](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.0.0-beta.2/MilesianLedger-v1.0.0-beta.2.zip)을 내려받아 원하는 폴더에 모두 압축 해제한 뒤 `MilesianLedger/MilesianLedger.exe`를 실행합니다. 압축 파일 내부에서 바로 실행하지 마세요. 별도 설치 프로그램은 없습니다.

[릴리스 페이지](https://github.com/jang9610-cyber/MilesianLedger/releases/tag/v1.0.0-beta.2)의 **Source code (zip/tar.gz)**는 개발용 소스입니다. 앱을 바로 사용하려면 파일 이름이 `MilesianLedger-v1.0.0-beta.2.zip`인 첨부 파일을 선택하세요.

기존 버전의 계획과 설정을 이어 쓰려면 다음 순서로 업데이트합니다.

1. 메인 앱과 PIP를 모두 닫고, 기존 실행 폴더 전체를 백업합니다.
2. 새 실행 ZIP을 **별도 폴더**에 모두 압축 해제합니다.
3. 기존 실행 폴더의 `data`에서 아래 개인 파일 중 존재하는 것만 새 실행 폴더의 `data`에 복사합니다.

| 개인 파일 | 저장 내용 |
| --- | --- |
| `progress.json` | 교역 계획·프리셋·준비 방식·체크 상태 |
| `progress-history.json` | 진행 상태 복원 기록 |
| `auction-settings.json` | 경매장 품목명 매핑·조회 설정 |
| `auction-cache.json` | 저장한 경매장 시세 |
| `pip-settings.json` | PIP 창 설정 |
| `appearance.txt` | 화면 모드 설정 |

새 앱을 실행해 계획과 체크 상태가 표시되는지 확인합니다. `data` 폴더 전체를 덮어쓰지 말고 위 파일만 옮기세요. `barter-data.json`, `item-acquisition.json`, `trade-planning.json`, `auction-proxy.json`은 새 배포본의 데이터와 서버 설정을 사용합니다. API 키 파일은 필요하지 않습니다.

## 1. 교역 계획 정하기

앱을 실행하면 그랜드마스터 상인 전환을 확인하는 안내가 먼저 나옵니다. 게임에서 직접 확인한 뒤 버튼을 눌러 메인 화면으로 들어갑니다.

**교역 계획**에서 오아시스·카루 숲·페라 화산·칼리다 호수의 교역소 카드를 열고, 교역품과 목표 수량을 선택합니다. 선택한 품목은 카드와 아이콘에 강조됩니다. 이 화면의 재료 표는 필요량을 확인하는 용도입니다.

마스터리·보증서·그랜드마스터 상인·운송수단·파트너 설정을 지정하면 참고 판매액과 운송 적재량을 함께 확인할 수 있습니다. 실제 판매액과 이동 경로에 따라 결과가 달라질 수 있습니다.

교역 프리셋은 4개 교역소 전체에 적용합니다.

- **성실한 상인**: 전 품목 최대 수량
- **체리피커**: 모든 교역소의 3~5티어 최대 수량
- **극한의 한탕**: 3~5티어 한 칸씩, 칼리다 호수는 5티어
- 사용자 프리셋: 원하는 품목과 수량을 정한 뒤 이름을 입력해 저장

## 2. 재료 준비 방식 정하기

**재료 준비 → 재료 준비 방식 설정**에서 재료 카드를 누릅니다. 최종 교환 재료부터 하위 재료까지, 경매장에서 살지 직접 만들지 직접 확보할지를 정합니다.

같은 재료를 여러 교역품에서 사용하면 필요한 양을 합산합니다. 공통 재료의 준비 방식을 다른 품목에도 함께 적용할 수 있는 제안 창에서는 적용할 항목을 선택한 뒤 완료하세요.

**준비 방식 프리셋 1~5**는 재료별 구매·제작 선택을 보관합니다. 현재 번호의 설정은 자동 저장되며 다른 번호를 눌러 전환합니다. **구매·제작 선택 초기화**는 재료별 선택과 제작법을 기본 구매 방식으로 되돌리는 기능입니다. 확인 창에서 범위를 확인하세요.

## 3. 시세 가져오기

배포본에는 Cloudflare 시세 서버 주소가 설정되어 있습니다. 사용자가 API 키를 발급하거나 앱에 입력할 필요 없이 갱신 버튼으로 시세를 가져올 수 있습니다. 연결 오류나 서버·넥슨의 호출 한도가 표시되면 해당 안내를 확인하세요. 교역 계획·체크리스트와 이미 저장된 시세는 계속 사용할 수 있습니다. 별도 배포본에서 서버 주소가 설정되지 않았다면 연결 준비 안내가 표시됩니다.

- **전체 시세 갱신**: 현재 구매 방식과 관계없이 지원하는 전체 재료 시세를 조회
- **구매품목만 갱신**: 현재 선택한 교역 계획에서 경매장 구매로 지정한 재료만 조회
- **갱신 중지**: 진행 중인 조회를 중지

앱 실행, 체크, 검색, 프리셋 전환은 시세 조회를 시작하지 않습니다. 갱신당 최대 500요청까지 진행하며 대상 품목을 모두 조회하면 종료합니다. 서버는 최근 조회 결과를 잠시 재사용하며, 캐시된 가격의 조회 시각은 원래 시각을 유지합니다. 서버의 호출 예산은 모든 사용자가 공유하므로 서버 한도 안내가 나오면 나중에 다시 시도하세요.

표시 가격은 마지막으로 확인한 최저 개당 가격입니다. 매물이 바뀌거나 필요한 수량만큼 최저가 매물이 없으면 실제 구매액은 달라집니다. 조회 실패와 호출 한도 안내가 나오면 해당 표시를 확인하세요.

## 4. 체크리스트로 준비하기

**경매장 구매 체크리스트**는 경매장에서 살 품목, **제작·확보 체크리스트**는 직접 만들거나 채집·구비할 품목을 보여 줍니다. NPC 구매품도 제작·확보 목록에 포함됩니다.

목록은 **하위 재료 → 중간 제작 단계 → 최종 교환 재료** 순서로 표시됩니다. 각 단계에서는 방직·천·가죽, 장작, 금속, 실리엔, 힐웬, 허브 등 같은 재료 분류를 모아 이름순으로 정렬합니다.

필요 수량을 모두 준비한 항목을 체크하면 준비율에 반영됩니다. 재료를 모았다고 제작품이 자동으로 완성되지는 않으므로 제작을 마친 뒤 해당 제작품도 체크하세요. 상위 품목을 구비하면 그에 필요한 하위 재료 몫도 준비율에 반영되며, 최종 교환 재료를 모두 체크하면 100%가 됩니다.

**남은 품목만 보기**를 켜면 완료되거나 상위 품목 구비로 충족된 항목이 숨겨집니다. 해제하면 전체 목록이 돌아옵니다. **목록 복사**로 구매·제작·직접 확보·NPC 구매 목록을 함께 복사할 수 있습니다.

## 5. PIP 사용하기

왼쪽 **PIP 체크리스트**를 눌러 작은 항상 위 창을 엽니다. 구매와 제작·확보 탭을 전환하며 확인할 수 있고, 체크와 남은 품목 필터는 메인 앱과 연동됩니다.

개발 빌드에서는 왼쪽 **PIP** 안에 **시세 검색** 탭도 있습니다. 아이템 이름을 입력하면 서버가 수집한 전체 시장 품목에서 찾습니다. `가는실뭉치`처럼 띄어쓰기를 생략하거나 이름의 일부만 입력해도 됩니다. 일치하는 이름을 먼저 보여 주며, 결과가 많으면 이름을 더 입력해 좁힐 수 있습니다.

인챈트 스크롤은 `템포`처럼 인챈트 이름으로 검색합니다. 결과는 `템포 (접미 / 랭크 6) · 전용 인챈트 스크롤` 형식이며, 접두·접미와 랭크, 일반·전용·개방된 전용 스크롤 종류를 구분해 시세를 보여 줍니다. 장비에 붙어 있는 인챈트 이름은 검색 대상에 포함하지 않습니다.

처음에는 **시세 받기**, 이후에는 **시세 갱신**으로 최신 공통 데이터를 받습니다. 검색어 입력과 탭 전환은 인터넷 조회를 하지 않으며, 받은 시세는 오프라인에서도 검색할 수 있습니다. 매물 수집 시각과 개당 최저가, 등록 건수·수량을 확인하세요. 서버의 매물 수집은 현재 3시간 간격이며 갱신 버튼이 실시간 경매장 수집을 시작하지는 않습니다. 옵션이 있는 장비는 같은 이름의 참고 최저가로 표시되므로 드랍된 장비의 옵션별 가치와는 다를 수 있습니다.

**인챈트 이름 미확인**으로 표시되는 스크롤은 여러 인챈트가 섞인 가격을 보여 주지 않습니다. **시세 갱신**으로 공통 데이터를 받은 뒤 인챈트 이름을 입력하세요. 기존에 스크롤 종류별로 합쳐 저장한 과거 거래는 이름별로 다시 나눌 수 없으며, 이름별 거래 기록은 새로 수집한 거래부터 쌓입니다.

PIP 위로 마우스를 옮기면 PIP가 입력 포커스를 받습니다. 첫 클릭부터 체크할 수 있으며 스크롤로 목록을 이동합니다. 창 가장자리에서 크기를 조절할 수 있습니다. `?`를 누르거나 마우스를 올리면 획득·제작 안내를 확인합니다.

게임 환경에 따라 PIP 클릭 이후 클릭 상태가 마비노기에 남을 수 있습니다. 앱은 게임 입력이나 게임 내부 상태를 직접 제어하지 않습니다.

## 계산 기준

- 나무판과 500 포션류는 완제품 경매장 구매 전용입니다.
- 새우·설탕·마늘은 NPC 구매이며 경매장 조회와 비용 합계에서 제외됩니다. 새우 조련 미끼 완제품은 구매와 제작 중에서 선택합니다.
- 금속괴는 합성 증식을 추천하며, 시작용 괴와 제작 결과의 체크는 별도로 관리합니다.
- 제작은 성공 기준입니다. 실패 소모량이나 사용자가 이미 가진 부분 수량을 따로 계산하지 않습니다.
- 비용은 선택한 준비 방식과 저장된 시세에 따른 예상 금액입니다. 실제 지출 장부나 게임 인벤토리와 자동 연결되지 않습니다.

## 저장·백업·복원

계획·체크·프리셋은 실행 폴더의 `data/progress.json`에 자동 저장됩니다. **진행 상태 복원**에서는 저장된 이전 상태로 되돌리거나 현재 상태를 직접 보관할 수 있습니다. 주간 리셋 전에 진행 상황을 확인하세요.

앱을 닫은 뒤 실행 폴더를 개인 보관용으로 복사하면 설정과 진행 상태를 함께 백업할 수 있습니다. 다른 사람에게 배포할 때는 이 개인 백업을 사용하지 말고 저장소의 배포 스크립트가 만든 ZIP을 사용하세요. 이 버전은 앱에서 API 키를 저장하지 않습니다. 예전 버전의 키 파일은 더 이상 사용하지 않으며 배포 ZIP에도 포함되지 않습니다.

다크 모드는 왼쪽 아래에서 바꾸며 메인과 PIP에 함께 적용됩니다. 자료의 근거와 개별 원문은 **출처** 창에서 확인할 수 있습니다.

## 시세 갱신 결과 확인

갱신 버튼 아래의 조회 실패는 요청했으나 가격을 확인하지 못한 품목 수입니다. 미갱신은 중단 또는 요청 한도 때문에 조회를 마치지 못한 품목 수입니다. 결과 안내에 마우스를 올리면 실패 품목과 사유를 볼 수 있습니다. 특정 품목의 검색 조건 오류는 다음 품목으로 넘어가며, 인증·호출 한도·서비스 장애가 확인되면 갱신을 중단합니다. 기존 시세가 있으면 유지합니다.
