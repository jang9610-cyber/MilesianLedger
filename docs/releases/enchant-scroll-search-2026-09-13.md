# 인챈트 스크롤 이름 검색 — 2026-09-13

개발 브랜치 `feature/market-statistics`, 버전 `1.1.0-dev.1`에서 인챈트 스크롤의 시세를 이름별로 구분한다. 공개 베타 Release는 `v1.0.0-beta.2`를 유지한다.

## 동작

- PIP의 **시세 갱신** 후 `템포`, `영감`처럼 인챈트 이름을 입력한다. 결과에는 인챈트 이름·접두/접미·랭크·스크롤 종류와 수집 당시 개당 최저가·매물 건수·수량을 표시한다.
- 일반·전용·개방된 전용 스크롤은 별도 품목이다. 장비에 붙은 인챈트는 검색 이름을 생성하는 데 사용하지 않는다.
- 인챈트 이름이 확인되지 않은 스크롤은 여러 종류가 섞인 최저가를 숨긴다. 기존 로컬 캐시의 가격에도 같은 처리를 적용한다.
- 검색어 입력과 탭 전환은 로컬 처리이며 서버 요청을 만들지 않는다. 갱신 버튼은 서버의 공통 압축 데이터를 받는다.

## 집계와 운영

공식 경매장 응답에서 `auction_item_category=인챈트 스크롤`, `option_type=인챈트 종류`, `option_sub_type=접두/접미`, `option_value=템포 (랭크 6)` 형식을 확인했다. 지원하는 기본 스크롤 이름에만 이를 적용해 `템포 (접미 / 랭크 6) · 전용 인챈트 스크롤`처럼 집계한다. 옵션이 없거나 서로 충돌하는 경우 임의의 인챈트 이름을 선택하지 않는다.

이미 저장된 과거 거래는 옵션 정보가 없어 소급 분리할 수 없다. 기존 거래 ID의 중복 제거를 유지하고 새 거래부터 이름별 기록을 쌓는다. 따라서 적용 직후 이름별 24시간·7일 통계는 해당 기간 전체를 포함하지 않는다. 현재 매물은 수정 후 전체 재수집한 완료본으로 교체했다.
