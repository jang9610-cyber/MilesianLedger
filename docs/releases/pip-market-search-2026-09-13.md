# PIP 아이템 시세 검색 — 2026-09-13

개발 브랜치 `feature/market-statistics`, 버전 `1.1.0-dev.1`의 PIP에 **시세 검색** 탭을 추가했다. 공개 베타 Release는 `v1.0.0-beta.2`를 유지한다.

## 사용과 데이터

- 아이템 이름의 일부나 띄어쓰기를 생략한 이름으로 전체 수집 품목을 검색한다. 정확한 이름을 먼저 표시하며 한 번에 최대 30개를 보여 준다.
- 개당 최저가, 등록 건수·수량, 매물 수집 시각을 표시한다. 장비와 분류 미확인 품목은 옵션별 가격 차이를 안내한다.
- PIP의 **시세 받기·갱신** 버튼이 메인 앱과 같은 공통 데이터 클라이언트를 호출한다. 검색과 탭 전환은 서버 요청을 만들지 않는다.
- 앱을 다시 켜도 검증된 저장 파일을 네트워크 요청 없이 읽는다. 갱신에 실패하면 이전 시세를 유지한다.
- 기존 구매·제작 체크리스트의 체크 연동, 검색어·스크롤 유지, 다크 모드, 마지막 탭 저장을 함께 지원한다.

매물 수집 주기는 현재 3시간이다. 검색 가격은 수집 당시의 관측값이며 옵션별 장비 감정이나 실시간 매물 확인을 뜻하지 않는다. 기존에 없는 아이콘은 대체 기호로 표시한다. Worker 코드나 운영 설정은 이번 변경에서 수정하지 않았다.

## 검증

- 검색 색인 8그룹: 동일 이름 통합, 공백·대소문자 검색, 정확한 원문 이름 우선, 서로 다른 이름 보존, 가격·수량 미확인, 20,000개 품목 검색.
- 공통 파일 17그룹: 기존 다운로드·해시·취소 검사와 재시작 후 로컬 복원·동시 읽기·손상 파일 처리의 추가 요청 0회 확인.
- PIP UI: 320×540·360×540 라이트/다크, 긴 이름, 소수 단가, 수량 미확인, 검색 결과 제한, 체크 동기화 콜백, 스크롤·검색어 보존, 갱신 실패·종료 취소·탭 저장.
- 기존 교역·재료·준비율·비용·프록시 코어 검사 통과.
- 실제 공통 파일: 검색 가능 이름 15,847종 중 가격이 있는 15,805종 전체의 검색 결과가 원본 단가·등록 건수·수량·수집 시각과 일치했다. 기존 교역 품목 117종 갱신도 통과했다.
- 실제 검증은 공통 manifest·gzip 2회와 동일 버전 확인 1회의 HTTP 요청으로 수행했고, 품목별 검색에는 추가 HTTP 요청이 없었다.
