# 공통 경매장 데이터 운영 전환 — 2026-09-13

개발 브랜치 `feature/market-statistics`, 앱 버전 `1.1.0-dev.1`에 공통 시세·시장 통계 다운로드를 연결했다. 공개 베타 Release는 `v1.0.0-beta.2`를 유지한다.

## 적용 구조

- Cloudflare가 거래 내역과 전체 매물을 공식 API에서 수집한다.
- SQLite 청크에 페이지와 커서를 함께 저장하며 거래 ID로 정확히 중복을 제거한다.
- 완료된 수집본으로 24시간·7일 통계와 교역 시세를 만들고 SHA-256 버전의 gzip 파일로 게시한다.
- 새 앱은 manifest를 확인하고 새 버전만 다운로드한다. 검색·정렬·목록 이동·교역 비용 계산은 로컬 데이터를 사용한다.
- 구버전 품목 조회 경로도 공통 게시본으로 응답하며 사용자 조회가 넥슨 요청을 추가하지 않는다.

## 무료 플랜 운영 설정

- 거래 내역: 20분 주기.
- 전체 매물: 180분 주기.
- 넥슨 공통 운영 예산: 최근 24시간 10,000회 중 시장 수집은 80%까지.
- SQL 내부 예산: UTC 날짜별 쓰기 60,000행·읽기 3,000,000행. 정상 네이티브 계측 작업은 실제 사용량에 여유분을 더해 정산하고, 미완료 예약은 유지한다.
- DB가 750MiB에 접근하면 신규 수집·게시를 차단한다. gzip 8MiB·원본 16MiB 등 크기 제한을 넘거나 수집이 실패하면 이전 완료본을 유지한다.

첫 실측 기준 정기 API 요청은 하루 약 `72 × 25 + 8 × 307 = 4,256회`다. 시간대별 거래량 증가·재시도·보관 데이터 정리 비용은 별도이므로 이 값은 보장치가 아닌 운영 추정이다. 예산 초과 시 부분 결과를 전체 완료로 처리하지 않는다.

운영 설정 파일은 `server/cloudflare/wrangler.market.jsonc`다. `MARKET_ENABLED`, `MARKET_SCHEDULE_ENABLED`, `SHARED_MARKET_QUOTES_ENABLED`를 활성화하며 `MARKET_LIST_INTERVAL_MINUTES=180`, `MARKET_PAGES_PER_ALARM=40`을 사용한다. 배포 버전: `f1e26cd9-e08f-4515-8622-63afe50fcbd5`.

## 검증과 범위

- 서버 테스트 70개: 실제 SQLite 원자성·중복 제거·무료 예산·배치 복구·공통 파일·구버전 호환 포함.
- 앱 스냅샷 검증 15그룹: SHA-256·크기·동일 버전·취소·오프라인 복원·만료한 매물 처리 포함.
- 기존 계산/교역 코어 검사와 WPF 밝은·어두운 테마 UI 검증 통과.
- 앱의 122품목 모의 갱신은 최초 2회, 동일 버전은 1회 HTTP 요청으로 처리했다.
- 실제 서버의 전체 117개 교역 품목도 공통 파일 최초 2회 요청 후 조건부 확인 1회로 모두 갱신했다. 가격·수집 시각·매물 수량이 공통 원본과 일치했고 실패 품목은 0개였다.
- 구버전 경로에서 거미줄·굵은 실뭉치·미스릴 광석을 조회했을 때 응답 출처는 `shared_snapshot`이었다. 관리자 계측의 넥슨 요청은 전후 341회로 동일하여 추가 요청 0회를 확인했다.

시장 통계는 수집한 거래 내역만 포함한다. 처음부터 7일 전체 기록이 존재하는 것은 아니며 시간이 지나면서 누적된다. 이미지·제작법의 추가 수집이나 자동 매매 기능은 이 변경에 포함되지 않는다. 가격은 수집 시각의 관측값이며 매물 전체 갱신 주기를 따른다.
