# 밀레시안 장부 1.0.0-beta.1 · 공개 베타

마비노기 물물교환 교역의 품목 선택부터 재료 준비까지 관리하는 Windows 데스크톱 앱입니다. 경매장 구매와 직접 제작·확보를 섞어 계획하고, 메인 앱과 PIP 체크리스트에서 준비 상태를 함께 관리할 수 있습니다.

**[Windows 실행 ZIP 다운로드](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.0.0-beta.1/MilesianLedger-v1.0.0-beta.1.zip)** · [GitHub 릴리스](https://github.com/jang9610-cyber/MilesianLedger/releases/tag/v1.0.0-beta.1)

## 주요 기능

- 4개 교역소의 1~5티어 교역품 20종 선택, 목표 수량과 운송 설정
- 완제품·하위 재료별 구매/제작/확보 설정과 공유 재료 합산
- 경매장 구매 및 제작·확보 체크리스트, 준비율과 남은 품목 필터
- 하위 재료부터 준비하도록 단계·재료 분류·이름순 정렬
- 메인과 연동하는 PIP 체크리스트, 아이템 아이콘과 획득 안내
- 전체 시세 및 구매품목만 갱신하는 두 버튼과 갱신 중지
- 교역·준비 방식 프리셋, 자동 저장·진행 상태 복원, 다크 모드

## 실행과 업데이트

**Windows와 .NET Framework 4.8 런타임**을 사용합니다. 서버 주소가 포함되어 있어 앱에 API 키를 입력할 필요는 없습니다.

처음 사용하는 경우 `MilesianLedger-v1.0.0-beta.1.zip`을 모두 압축 해제한 뒤 `MilesianLedger` 폴더의 `MilesianLedger.exe`를 실행하세요. 실행 파일과 `data`, `assets` 폴더를 함께 보관합니다. 별도 설치 프로그램은 없습니다.

GitHub의 **Source code (zip/tar.gz)**는 개발용 소스 압축이며 바로 실행할 앱이 아닙니다.

기존 버전에서 업데이트할 때는 앱과 PIP를 모두 닫고 실행 폴더 전체를 백업합니다. 새 ZIP을 별도 폴더에 푼 뒤 기존 `data`의 `progress.json`, `progress-history.json`, `auction-settings.json`, `auction-cache.json`, `pip-settings.json`, `appearance.txt` 중 존재하는 파일만 새 `data`에 복사합니다. 새 배포본의 정적 데이터와 서버 주소를 유지할 수 있도록 `data` 전체를 덮어쓰지 않습니다.

## 베타 사용 시 참고 사항

- PIP는 별도의 Windows 창입니다. 게임 환경에 따라 포커스가 바뀌거나 PIP 조작 후 클릭 상태가 게임에 남을 수 있습니다. 앱은 게임 입력과 메모리를 직접 제어하지 않습니다.
- 시세는 갱신 버튼을 눌렀을 때만 조회합니다. 서버 호출 예산을 모든 사용자가 공유하므로 서버나 넥슨 한도에 도달하면 갱신이 중단될 수 있습니다.
- 표시 가격과 비용은 저장된 최저 개당 시세에 따른 예상값입니다. 실제 매물 수량·시세 변동·제작 실패 비용 등에 따라 실제 지출이 달라질 수 있습니다.
- 구비 체크는 필요 수량 전체를 준비했다는 표시이며 부분 보유 수량이나 게임 인벤토리를 자동으로 읽지 않습니다.
