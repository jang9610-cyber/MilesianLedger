# 밀레시안 장부 1.0.0-beta.2 · 경매장 조회 개선

전체 시세 갱신에서 미스릴 광석 계열의 검색 오류가 발생하면 이후 품목까지 미갱신으로 남던 문제를 수정했습니다.

**[Windows 실행 ZIP 다운로드](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.0.0-beta.2/MilesianLedger-v1.0.0-beta.2.zip)**

## 변경 사항

- 미스릴광석·미스릴광석 조각의 경매장 검색명을 교정했습니다. 기존 재료 준비 방식과 구비 체크의 저장 키는 유지합니다.
- 특정 품목의 검색 조건 오류는 해당 품목만 실패로 표시하고 다음 품목을 계속 조회합니다. 인증·호출 한도·서비스 장애가 확인되면 전체 갱신을 중단합니다.
- 갱신 결과에서 실제 조회 실패와 요청하지 못한 미갱신을 구분합니다. 중단 사유와 실패 품목을 확인할 수 있습니다.
- 서버는 이전 베타의 검색명도 지원하여 기존 앱과 호환됩니다.
- 서버 공용 운영 예산을 최근 24시간 500회에서 10,000회로 확대했습니다. 초당 요청 제한과 앱의 갱신당 500회 상한은 유지합니다. 넥슨 키의 실제 한도와는 별도인 서버 운영 설정입니다.
- 개발용 전체 품목 실서버 검증 명령을 추가했습니다. 기본 테스트·CI·앱 실행 시에는 자동 호출하지 않습니다.

## 검증

- 지원하는 117종의 실제 경매장 조회와 가격 응답, 임시 시세 저장·복원을 확인했습니다.
- 품목별 검색 오류 이후 조회 진행, 인증·호출 제한 시 중단, 구버전 검색명 호환을 모의 응답으로 검증했습니다.
- Windows 빌드, 계산·화면·PIP 및 두 프록시의 회귀 검증을 수행했습니다.

실제 조회 결과는 검증 시점의 상태입니다. 이후 매물과 서버 상태는 달라질 수 있습니다.

## 실행과 업데이트

Windows와 .NET Framework 4.8 런타임을 사용합니다. ZIP을 모두 압축 해제한 뒤 `MilesianLedger/MilesianLedger.exe`를 실행하세요. GitHub의 **Source code** 압축은 실행 파일이 포함된 배포 ZIP이 아닙니다.

기존 앱과 PIP를 닫고 기존 폴더를 백업한 뒤 새 ZIP을 별도 폴더에 풉니다. 기존 `data`의 `progress.json`, `progress-history.json`, `auction-settings.json`, `auction-cache.json`, `pip-settings.json`, `appearance.txt` 중 존재하는 파일만 새 `data`로 복사하면 개인 설정을 이어 사용할 수 있습니다. 새 정적 데이터와 서버 주소를 유지하도록 `data` 전체를 덮어쓰지 않습니다.

업데이트 후 **전체 시세 갱신**을 누르면 교정된 검색명으로 조회합니다. 앱에 API 키를 입력할 필요는 없습니다.
