# 밀레시안 장부 1.1.0-beta.1 · 교역·경매장·분배

교역 준비에 시장 통계, 경매장 검색, 판매 수수료·분배 계산을 더한 공개 베타입니다. 시장 통계와 분배는 메인 앱 안에서 전환하고, PIP는 교역 체크리스트와 직접 입력 경매장 검색을 제공합니다.

**[Windows 실행 ZIP 다운로드](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.1.0-beta.1/MilesianLedger-v1.1.0-beta.1.zip)**

## 주요 변경 사항

- 서버가 정기 수집한 공통 압축 시세를 받아 앱에서 검색·정렬·계산합니다. 같은 버전의 중복 다운로드와 품목별 넥슨 호출을 줄였습니다.
- 최근 24시간·7일 시장 통계, 게임 경매장 형태의 분류 메뉴, 관심 품목, 판매 기회 필터를 추가했습니다.
- 평균 거래가가 최저 매물가의 5배 이상인 품목을 기본 목록에서 제외하고 위험군 목록에서 따로 확인할 수 있습니다. 유동 옵션 품목의 평균 비교를 제한하며 기록된 최저 매물가는 표시합니다.
- PIP에 고정된 교역·경매장 검색 탭을 제공합니다. 구매·제작 체크리스트와 준비율은 교역 탭에 모았으며 메인 앱과 연동됩니다.
- 이름·초성 혼합 검색과 인챈트 이름 검색을 지원합니다. 일반·전용·개방된 전용 인챈트 스크롤을 구분합니다.
- 실제 판매 금액을 직접 입력하는 수수료·분배 계산기를 추가했습니다. 쿠폰 시세·실제 구매 비용을 반영하고 유리한 방식을 강조하며 분배표를 이미지로 복사할 수 있습니다.
- 분배 초기화는 쿠폰 비용과 입력 방식을 유지합니다. 경매장 갱신으로 아이템 참고 시세와 할인 쿠폰 시세를 함께 받습니다.
- 메뉴 그룹, 드롭다운·화면 전환 디자인을 통일했습니다. 교역 진행 상태 복원은 교역 계획과 재료 준비 화면에서 제공합니다.
- 개발 빌드의 OCR·화면 촬영·Raw Input 단축키 기능과 관련 설정을 제거했습니다. 직접 입력 검색과 분배표 이미지 복사는 유지됩니다.
- README와 사용 안내를 현재 메뉴와 기능에 맞춰 정리했습니다.

## 설치와 업데이트

Windows 10/11과 .NET Framework 4.8이 필요합니다. ZIP을 모두 풀고 `MilesianLedger/MilesianLedger.exe`를 실행하세요. 별도 API 키나 Windows SDK, OCR 언어 팩은 필요하지 않습니다.

기존 메인 앱과 PIP를 닫고 실행 폴더를 백업한 뒤 새 ZIP을 별도 폴더에 풉니다. 이전 `data`의 개인 진행·설정 파일만 복사하고 새 정적 데이터를 덮어쓰지 마세요. [옮길 개인 파일 목록](https://github.com/jang9610-cyber/MilesianLedger/blob/v1.1.0-beta.1/docs/USER_GUIDE.md#설치와-업데이트)을 참고하세요. 예전 촬영 단축키 설정은 사용하지 않습니다.

## 검증과 참고 사항

Windows PowerShell 빌드·패키징, 교역 계산·저장, 공통 시세 다운로드, PIP 검색·체크 연동, 메인 화면 전환, 분배 화면 검증을 통과했습니다. 시장 필터 1,114개와 분배 화면 3,327개 항목, 서버 테스트 123개를 확인했습니다. 검증은 모의 데이터로 실행했으며 게임 입력이나 실제 경매장 API 호출을 생성하지 않았습니다.

시세는 서버 수집 시점의 참고 정보입니다. 갱신 버튼은 게시된 공통 데이터를 받으며 즉시 전체 경매장을 재수집하지 않습니다. PIP 조작 후 클릭 상태가 게임에 남는 환경별 문제는 해결된 것으로 보장하지 않습니다.
