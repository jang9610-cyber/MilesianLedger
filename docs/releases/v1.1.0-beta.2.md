# 밀레시안 장부 v1.1.0-beta.2

앱 시작 화면을 경매장 정보 로딩 화면으로 변경했습니다.

- 그랜드마스터 상인 전환 질문과 시작 확인 버튼을 제거했습니다.
- 시작할 때 서버의 공통 경매장 시세를 불러와 교역 가격·PIP 검색·시장 통계·분배 참고 시세에서 함께 사용합니다. 서버의 전체 수집을 새로 실행하지 않습니다.
- 로딩 완료 후 2초 뒤 메인 화면으로 자동 전환합니다. 완료 후 대기 중에도 마차 애니메이션은 계속 재생됩니다.
- 연결 실패 시 이전 시세를 유지하며, 저장된 시세가 없어도 앱을 열 수 있습니다. × 또는 Esc로 실행을 취소할 수 있습니다.
- GitHub Actions에서 태그의 소스를 빌드·검증·패키징하고 ZIP과 SHA-256 파일을 직접 릴리즈에 게시하도록 구성했습니다.

## 다운로드와 업데이트

[Windows 실행 ZIP](https://github.com/jang9610-cyber/MilesianLedger/releases/download/v1.1.0-beta.2/MilesianLedger-v1.1.0-beta.2.zip)을 모두 압축 해제한 뒤 `MilesianLedger.exe`를 실행하세요. Windows 10/11 및 .NET Framework 4.8이 필요합니다.

업데이트 전 메인 앱과 PIP를 닫고 기존 폴더를 백업하세요. 새 ZIP을 별도 폴더에 풀고 개인 진행·설정 파일을 옮기는 방법은 [사용 안내](https://github.com/jang9610-cyber/MilesianLedger/blob/v1.1.0-beta.2/docs/USER_GUIDE.md#설치와-업데이트)를 참고하세요.

## 검증과 참고

시작 화면의 성공·연결 실패·완료 후 2초 대기·애니메이션 지속·실행 취소·메인 창 전환을 오프라인 WPF 검증으로 확인했습니다. 경매장 공통 데이터 다운로드와 교역 계산은 별도 회귀 검증으로 확인합니다.

시세는 서버 수집 시점의 참고 자료이며 실시간 매물을 보장하지 않습니다. 기존 PIP의 게임 환경별 클릭 상태 문제는 이번 변경의 수정 대상이 아닙니다.

데이터·이미지 출처와 권리는 [README](https://github.com/jang9610-cyber/MilesianLedger/blob/v1.1.0-beta.2/README.md#출처와-권리)에 안내되어 있습니다.
